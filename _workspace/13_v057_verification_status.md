# v0.5.7 보급 규칙·검증 상태 기록

## 구현 및 검사
- 보급 회복 비용을 병력 비례로 변경: `회복 보급률 × 병력 / 1,000 × 2` 군량.
- 군단 순서대로 계산하는 기존 배분 방식은 유지하고, 군량 부족 시 군단별 순번·배분 전 잔량·예상 회복량·예상 군량 소모를 표시.
- 보급 상한은 100. 기본 회복 +30, 연결 보급기지 추가 +20(턴당 최대 +50)은 시범값으로 유지.
- 구현 계산 검증과 JS 구문 검사, `git diff --check` 완료.

## 브라우저 검증 미완료
사용자가 제공한 화면에는 Chrome에서 `127.0.0.1:8081/index.html` 게임이 열려 있고, 로비의 역사·창작 안내 모달이 표시되어 있음이 확인된다. 이전의 브라우저 미검증은 게임 창이 닫혀 있었기 때문이 아니라, 자동화 도구가 사용자의 열린 브라우저 세션에 연결하지 못한 데서 발생했다.

아래 항목은 실제 브라우저 조작을 수행하지 못해 미검증 상태다.
- 저장 → 새로고침 → 불러오기: 군단 위치·병력·보급률·고갈 단계·장수·턴 보존.
- 실제 병합 → 이동 → 전투: 정상 진행, 혼성 병종 유지, 장수 중복·군단 참조 오류 여부.
- 실제 거점 점령 후 보급 재연결: 경로 표시, 예상 회복과 실제 회복 일치.

브라우저 연결 재시도와 추가 기능 수정은 이 기록 시점부터 중단한다.
