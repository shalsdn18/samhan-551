# 퀘스트 설계 문서

## 퀘스트 개요
- **총 퀘스트 수**: 메인 4개 + 사이드 5개
- **예상 플레이타임**: 8~12시간 (프롤로그~엔딩, 대전략 레이어 플레이타임은 별도)
- **난이도 곡선**: 초반(동맹 구축, 낮음) → 중반(기습 결정/배신 대응, 급상승) → 후반(관산성, 최고조) → 후일담(선택에 따른 수습)

## 메인 퀘스트 라인

### MQ-01: 한강으로 (나제동맹 결성)
- **개요**: 백제와 신라가 고구려의 한강 유역을 공동 공략하기로 합의하고 전역을 개시한다.
- **시작 조건**: 게임 시작(551년) — 백제·신라 양 시점 공통 오프닝
- **핵심 갈등**: 동맹의 실익 배분을 어떻게 사전에 합의하는가 — 이 합의의 모호함이 후반 배신의 씨앗
- **단계**:
  1. 사신 교환 — 목표: 백제·신라 간 전역 협정 체결, 힌트: 영토 분배 조항을 명확히 할지 모호하게 둘지 선택
  2. 공동 전역 — 목표: 한강 하류(백제)·상류(신라) 각각 공략, 선택지: 상대 전선에 지원군을 보낼지(신뢰 축적) 자원을 아낄지(실리)
  3. 승전 보고 — 목표: 전역 성공 선포, 이벤트: 양국 조정 내 "이 성공을 어떻게 써먹을까" 논의(복선)
- **보상**: 경험치 낮음 / 아이템: 없음(초반) / 스토리 해금: 영토 분배 조항의 명확성 여부가 MQ-02 발생 확률·강도에 영향
- **실패 조건**: 전역 실패 시 고구려가 한강을 유지 — 대체 루트(장기전 서브플롯)로 전환
- **분기 포인트**: 협정 모호성, 상호 지원 여부 → 분기설계자 참조

### MQ-02: 그림자의 무게 (553년 기습)
- **개요**: 신라가 백제가 되찾은 한강 하류까지 기습 점령한다. 플레이어가 신라라면 "결정"의 주체, 백제라면 "배신당함"의 주체가 된다.
- **시작 조건**: MQ-01 완료 후 시간 경과(2년) + 신라 내부 전략 회의
- **핵심 갈등**: (신라) 동맹을 깨는 대가로 영토 전체를 가질 것인가, 신뢰를 지키고 절반에 머물 것인가 / (백제) 배신의 징후를 사전에 감지했을 때 선제 대응할 것인가 묵인할 것인가
- **단계**:
  1. (신라) 이사부의 경고 — 목표: 기습의 정치적 후폭풍 보고를 듣는다, 선택지: 경고를 듣고 절반만 취한다 / 전체를 취한다
     (백제) 첩보 입수 — 목표: 신라의 이상 동향 정보를 받는다, 선택지: 선제 방어선 구축 / 동맹을 믿고 무시
  2. 기습/피습 — 목표: (신라) 한강 하류 점령 실행 / (백제) 갑작스런 상실에 대응, 보스/이벤트: 조정 내 격렬한 논쟁
  3. 국서 단절 — 목표: 나제동맹 공식 파기, 선택지: (백제) 즉각 선전포고 / 외교적 항의 후 시간을 번다
- **보상**: (신라) 영토 확장, 민심 상승 / 신뢰도 급락 (백제) 명분(정당성) 획득, 영토·전력 손실
- **실패 조건**: 없음(역사적 분기점이므로 "실패"가 아니라 "선택"으로 처리) — 다만 선택에 따라 후속 전력 격차가 달라짐
- **분기 포인트**: 신뢰도 자원과 영토 자원의 트레이드오프 — 분기설계자 핵심 소재

### MQ-03: 복수의 설계 (출정 준비)
- **개요**: 백제(성왕)가 보복을 결정하고, 왕자 여창을 비롯한 조정이 전쟁 준비에 돌입한다. (신라 시점에서는 "다가오는 전쟁에 대한 대비")
- **시작 조건**: MQ-02 완료 + 명분 자원 보유(백제) / 정보 자원 보유(신라)
- **핵심 갈등**: (백제) 복수의 규모를 어디까지 할 것인가 — 국력을 모두 거는 총력전인가, 제한전인가 / (신라) 선제 매복을 준비할 것인가, 정면 대응할 것인가
- **단계**:
  1. 조정 회의 — 목표: 전쟁 규모 결정, 선택지: 총력전(성왕 친정) / 제한전(장수 파견)
  2. 동맹 모색 — 목표: 가야·왜 등에 지원 요청, 선택지: 가야에 실질적 대가를 제시 / 명분만으로 요청
  3. 진군 — 목표: 관산성 방면으로 이동, 이벤트: 여창의 조급함(단독 선발대 파견 유혹)
- **보상**: 가야의 지원(또는 거부) 여부가 MQ-04 난이도에 직결 / 여창 관련 관계 플래그 변화
- **실패 조건**: 동맹 모색 완전 실패 시 MQ-04가 더 큰 열세로 시작
- **분기 포인트**: 총력전/제한전 선택이 성왕의 전사 가능성 자체에 영향 — 분기설계자 핵심

### MQ-04: 관산성 (클라이맥스)
- **개요**: 백제·신라 양군이 관산성에서 격돌한다. 역사적으로 성왕이 이곳에서 전사하지만, 플레이어 선택이 전사 여부·규모·이후 구도를 바꾼다.
- **시작 조건**: MQ-03 완료
- **핵심 갈등**: (백제) 선발대의 위기를 구하러 왕이 직접 나설 것인가(역사적 결정, 고위험) 전령을 보내 후퇴시킬 것인가 / (신라) 매복을 상비군으로 상대할 것인가 특수부대(복병)로 처리할 것인가
- **단계**:
  1. 선발대 위기 — 목표: 여창이 이끈 선발대가 고전, 선택지: (백제) 성왕 친히 구원 / 전령만 파견
  2. 매복 발각 혹은 성공 — 목표: 신라 측 매복 작전 실행, 선택지: (신라) 왕을 포로로 / 전사시킴 / 퇴로를 열어줌(관계·명분 소재)
  3. 전후 수습 — 목표: 양국 조정의 충격 수습, 이벤트: 후계·숙청 문제 발생
- **보상**: 역사 분기 콘텐츠 해금(엔딩으로 직결), 주요 인물 생사 확정
- **실패 조건**: 없음 — 모든 결과가 "엔딩의 재료"로 설계됨(분기설계자 참조)
- **분기 포인트**: 전사/생존/포로, 여창의 생사와 심리 상태 → 엔딩 전체의 분기 원점

## 사이드 퀘스트

### SQ-01: 6두품의 분노 (신라)
- **개요**: 능력은 있으나 진골이 아니라 승진에 막힌 관료가 불만을 토로한다.
- **시작 NPC/조건**: 금성의 6두품 문관
- **메인 스토리 연관**: 신라의 급성장이 내부 모순(골품제)을 심화시킨다는 것을 보여줌
- **단계**: 그의 공적 조사 → 등용 방식 결정(파격 등용/관례 존중) → 결과 반영
- **보상**: 등용 시 행정 효율 상승이나 진골 귀족 반발 / 거절 시 해당 인물이 이후 반란·망명 서브플롯으로 재등장
- **숨겨진 요소**: 파격 등용 시 그가 MQ-04 이후 수습 과정에서 핵심 조력자로 재등장

### SQ-02: 22담로의 왕족 (백제)
- **개요**: 지방 담로에 파견된 왕족이 중앙의 명령과 지역 실정 사이에서 갈등한다.
- **시작 NPC/조건**: 지방 담로 파견 왕족
- **메인 스토리 연관**: 백제의 지방 통치 구조(교역·행정)를 조명, MQ-03 전쟁 자원 동원과 연결
- **단계**: 지역 분쟁 조정 → 중앙 동원령 전달 → 지역 반발 또는 협조 결정
- **보상**: 협조 시 MQ-03 전쟁 자원 보너스 / 반발 시 지방 이반 리스크
- **숨겨진 요소**: 해상 교역로를 통한 왜와의 비공식 지원 채널 발견 가능

### SQ-03: 양다리의 대가 (대가야)
- **개요**: 가야 연맹 수장이 백제·신라 양쪽에 각기 다른 약속을 했음이 드러날 위기에 처한다.
- **시작 NPC/조건**: 대가야 교역항, MQ-03 진행 중 접근 가능
- **메인 스토리 연관**: 약소국 시점에서 메인 갈등을 다른 각도로 조명
- **단계**: 양쪽 밀서 존재 확인 → 한쪽에 진실을 흘릴지/숨길지 결정 → 결과에 따른 가야의 입지 변화
- **보상**: 숨김 성공 시 단기적 안전, 하지만 발각 시 양쪽 모두의 신뢰 상실(장기 페널티)
- **숨겨진 요소**: 신라에 진실을 흘리면 SQ-01의 6두품 인물과 연결되는 정보 루트 발견

### SQ-04: 태학의 그림자 (고구려, 확장 서브플롯)
- **개요**: 고구려가 남방 방어선 약화를 북방(돌궐·북제) 압박 탓으로 돌리며 내부 책임 공방이 벌어진다.
- **시작 NPC/조건**: 평양 조정 내 장군
- **메인 스토리 연관**: 백제·신라의 성공이 고구려 내부 정치의 결과이기도 함을 보여줌(선악 이분법 회피)
- **단계**: 남방 실책 조사 → 책임 소재 규명(귀족 숙청 vs 체제 개혁) → 차기 남진 전략 수립
- **보상**: 개혁 선택 시 장기적으로 고구려 반격 강화(확장팩 연계), 숙청 선택 시 단기 안정이나 인재 손실
- **숨겨진 요소**: 신라와의 밀약설 루트와 연결되는 복선

### SQ-05: 화랑의 첫 전장 (신라)
- **개요**: 화랑도에서 막 나온 젊은 인재가 첫 실전(MQ-02 혹은 MQ-04)에 배치된다.
- **시작 NPC/조건**: 금성, 화랑도 수료식 이후
- **메인 스토리 연관**: 인재 육성 시스템을 체험형으로 보여줌, 플레이어의 "성장시킨 인물"이 클라이맥스에 등장
- **단계**: 수련 — 선택(용맹/신중 특성 강화) → 실전 배치 → 생존 또는 전사(선택 결과에 따른 확률)
- **보상**: 생존 시 이후 챕터/확장의 주요 장수로 성장, 전사 시 관계 있던 NPC들의 반응 이벤트(감정적 보상)
- **숨겨진 요소**: 신중 특성으로 키우면 이사부의 눈에 들어 SQ-01 조력자 루트와 합류 가능

## 퀘스트 흐름도
```
MQ-01(동맹 결성)
   │
   ├─ SQ-01(6두품), SQ-02(담로), SQ-05(화랑) ← 병행 가능
   │
MQ-02(기습/배신) ← 협정 모호성 여부(MQ-01)가 강도 결정
   │
   ├─ SQ-03(가야 양다리) ← MQ-02 이후 긴장 고조로 트리거
   │
MQ-03(복수 설계) ← SQ-02 결과가 자원 보너스로 반영
   │
   ├─ SQ-04(고구려 내부) ← 병행, 확장 복선
   │
MQ-04(관산성, 클라이맥스) ← SQ-05에서 키운 인물 등장 가능
   │
   └─ 분기설계자 엔딩 구조로 연결
```

## 대사 작가 전달 사항
- MQ-02는 양 시점(신라/백제) 대사가 **완전히 달라야** 한다 — 같은 사건을 가해자/피해자 시점에서 서술
- MQ-04 클라이맥스는 대사-침묵 리듬(바크 시스템 가이드 참조)을 강하게 적용 — 결정적 순간엔 대사를 줄이고 긴 침묵/연출로 처리
- SQ-05의 화랑 캐릭터는 생존/전사 양쪽 분기 대사를 모두 준비

## 분기 설계자 전달 사항
- 분기 원점 3곳: MQ-01(협정 명확성), MQ-02(절반/전체 기습, 또는 선제대응/묵인), MQ-04(친정/전령, 전사/포로/퇴로)
- 누적형 자원: 신뢰도(백제↔신라), 가야 호감(백제/신라 양쪽), 성왕-여창 관계
- SQ-01/SQ-05의 인물 생존 여부는 엔딩 에필로그의 "인물 목록"에 반영되어야 함
