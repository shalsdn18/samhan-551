# 내러티브 검증 보고서

## 종합 평가
- **개발 준비 상태**: 🟡 수정 후 진행
- **총평**: 세계관(553년 나제동맹 붕괴~관산성)과 퀘스트·대사·분기가 하나의 일관된 역사적 비극을 중심으로 잘 엮여 있다. 다만 엔딩 우선순위 규칙과 선택지-플래그 간 1:1 매핑 표기가 보완되면 제작 단계에서 모호함이 줄어든다.

## 발견 사항

### 🔴 필수 수정 (플롯홀/논리 모순)
없음 — 역사적 뼈대(나제동맹→기습→관산성)를 유지하면서 결과만 변주하는 구조라 시간선·인과관계 단절이 발견되지 않음.

### 🟡 권장 수정 (밸런스/개선)
1. **엔딩 우선순위 규칙 부재**: `GOGURYEO_pact=TRUE AND outcome≠KING_DIES` 조건(히든: 북방의 그림자)이 엔딩 B·D의 조건과 동시에 충족될 수 있다.
   - 현재: 우선순위 명시 없음
   - 제안: "히든 엔딩 조건이 메인 엔딩 조건과 동시 충족될 경우 히든 엔딩이 우선한다"는 규칙을 04_branch_map.md에 한 줄 추가
2. **CS-04 선택지 레터와 BP-03 플래그 매핑 불일치**: 대사 스크립트의 백제측 선택지(🅰️친정/🅱️불참)와 신라측 선택지(🅰️포로/🅱️전사/🅲️퇴로)가 분기 문서의 BP-03(🅰️~🅳️ 4항목, 양측 결합형)과 1:1로 바로 대응되지 않아 제작 시 혼동 가능
   - 제안: 분기 문서에 "CS-04 백제 선택 × 신라 선택 → BP-03 결과" 매핑 표를 추가(예: 친정×전사→A, 친정×포로→B, 불참×(포로/전사/퇴로)→C, (친정/불참)×퇴로→D)
3. **MQ-01에서 "신뢰에 맡김(문서 없음)" 선택(🅲️)이 분기 문서 BP-01에서는 다뤄지나, 퀘스트 문서에선 세 번째 선택지로만 짧게 언급됨**
   - 제안: 퀘스트 문서 MQ-01 단계 설명에 이 선택이 `TREATY_clarity=NONE`으로 직결된다는 점을 명시(현재는 분기 문서에만 플래그명이 있음)
4. **SQ-05(화랑)의 생존/전사 분기가 엔딩 에필로그 서술에 직접 반영되는 메커니즘이 명시되지 않음**
   - 제안: 분기 문서 "리플레이 가이드" 아래에 "주요 사이드 인물 생존 여부 → 에필로그 인물 목록" 규칙을 한 줄 추가

### 🟢 참고 사항
1. 가야 세력의 두 히든엔딩 조건(쇠의 나라)이 다소 조용히 묻히기 쉬움 — SQ-03 완료 시 UI상 "가야의 선택이 기록되었다" 같은 피드백을 주면 플레이어가 존재를 인지하기 쉬움
2. 고구려 시점(SQ-04)은 현재 서브플롯 수준인데, 세계관 문서에서 "선악 이분법 회피"를 핵심 원칙으로 제시한 만큼 추후 확장팩에서 고구려를 완전한 플레이 가능 세력으로 격상할 여지를 열어둔 것은 적절함

## 정합성 매트릭스
| 검증 항목 | 상태 | 비고 |
|----------|------|------|
| 세계관 ↔ 퀘스트 | ✅ | 세력 관계·역사 타임라인이 MQ 체인에 그대로 반영됨 |
| 퀘스트 ↔ 대사 | ✅ | MQ-02/04의 양 시점 대사가 퀘스트의 선택 구조와 일치 |
| 대사 ↔ 분기 | ⚠️ | 위 🟡-2 매핑 불일치 — 수정 권장이나 치명적이지 않음 |
| 분기 경로 완결성 | ✅ | 모든 BP-03 결과가 전후 수습 장면으로 합류, 막다른 길 없음 |
| 캐릭터 일관성 | ✅ | 성왕(학자적·절제), 진흥왕(실용·결단), 이사부(직설), 여창(격정→죄책감)이 세계관 설정과 대사에서 일관되게 유지됨 |
