# 분기 구조도

## 분기 개요
- **총 분기점**: 5개 (핵심 3 + 서브 2)
- **엔딩 수**: 6개 (메인 4 + 히든 2)
- **예상 회차별 플레이타임**: 8~10시간 (1회차), 분기 탐색 포함 재플레이 시 +4~6시간
- **리플레이 가치**: 같은 사건(나제동맹 붕괴~관산성)을 백제/신라 양 시점에서 전혀 다른 감정으로 체험, 숨겨진 외교 트랙(고구려 밀약) 발견 유도

## 구조 선택 근거
메인 스토리는 **병목 구조**(역사적 사건은 고정 지점 — 관산성 전투는 반드시 일어난다)로 제어하고, 결과의 "방식과 강도"는 **상태 누적 구조**(신뢰도, 가야 호감, 관계 플래그)로 설계한다. 가야 서브플롯은 독립적인 **나뭇가지 구조**로 짧게 처리한다. → 하이브리드 구조.

## 핵심 분기점

### BP-01: 맹약의 조항 (MQ-01 / CS-01)
- **상황**: 한강 분배를 명문화할 것인가, 모호하게 둘 것인가
- **선택지**:
  - 🅰️ 명문화: 즉시 결과 — 전역 속도 약간 저하 / 장기 결과 — 이후 신라의 배신이 발생해도 백제의 명분이 강해짐 / 플래그: `TREATY_clarity = HIGH`
  - 🅱️ 모호하게: 즉시 결과 — 전역 속도 상승 / 장기 결과 — 배신 발생 시 "누구 잘못인지" 모호해짐(양쪽 다 부분적 정당성) / 플래그: `TREATY_clarity = LOW`
  - 🅲️ 신뢰에 맡김(문서 없음): 즉시 결과 — 양측 체면 유지 / 장기 결과 — 신뢰도 변동폭이 가장 커짐(초기 신뢰 +, 배신 시 충격 최대) / 플래그: `TREATY_clarity = NONE`
- **합류 지점**: MQ-02 진입 시 모두 합류하되, `TREATY_clarity` 값이 BP-02의 선택 결과 가중치에 반영됨

### BP-02: 저울의 무게 (MQ-02 / CS-02)
- **상황**: (신라) 절반만 취할지 전부 취할지 / (백제) 선제 대응할지 묵인할지
- **선택지**:
  - 🅰️ (신라)절반만 / (백제)선제 대응: 즉시 결과 — 충돌 규모 축소 / 장기 결과 — 신뢰도 중간 수준 유지, MQ-04 피해 규모 감소 / 플래그: `SILLA_raid_scope = PARTIAL` 또는 `BAEKJE_response = PREEMPT`
  - 🅱️ (신라)전부 / (백제)묵인: 즉시 결과 — 영토·명분 극대화 / 장기 결과 — 신뢰도 붕괴, MQ-04 규모·격렬함 최대 / 플래그: `SILLA_raid_scope = FULL` 또는 `BAEKJE_response = IGNORE`
  - 🅲️ 참모에게 위임: 결과는 해당 참모(이사부 등) 성향에 따라 A/B 중 하나로 확정, 단 관계 플래그 `REL_isabu` 상승
- **합류 지점**: MQ-03에서 양측 모두 "전쟁으로 간다"는 결론은 같되, 전쟁 규모·자원이 달라짐

### BP-03: 관산성의 선택 (MQ-04 / CS-04) — 최대 분기점
- **상황**: (백제) 성왕 친정 여부 / (신라) 매복 결과 처리(포로/전사/퇴로)
- **선택지**:
  - 🅰️ 성왕 친정 + 신라가 전사시킴: 역사적 경로. 즉시 결과 — 백제 국력·사기 급락 / 장기 결과 — 여창의 복수심 최대, 향후 수십 년 적대 고착 / 플래그: `GWANSAN_outcome = KING_DIES`
  - 🅱️ 성왕 친정 + 신라가 포로로: 즉시 결과 — 백제 조정 혼란(섭정 문제) / 장기 결과 — 외교전(석방 교섭) 서브플롯 개방, 신라 내부 강경파·온건파 갈림 / 플래그: `GWANSAN_outcome = KING_CAPTURED`
  - 🅲️ 성왕 불참(여창 단독) + 어떤 결과든: 즉시 결과 — 성왕 생존 / 장기 결과 — 여창의 리더십 조기 시험대, 다만 "아버지가 오지 않았다"는 해석이 두 사람 관계에 그림자를 남김 / 플래그: `GWANSAN_outcome = KING_ABSENT`
  - 🅳️ (신라) 퇴로를 열어줌(성왕 친정 시에도 적용 가능): 즉시 결과 — 백제 피해 최소화 / 장기 결과 — 신라 강경파 반발, 숨겨진 외교 트랙(BP-04) 개방 / 플래그: `GWANSAN_outcome = KING_SPARED`
- **합류 지점**: 모든 경로는 MQ-04 이후 "전후 수습" 장면으로 합류하되, 합류 방식(섭정 vs 복수 선언 vs 애도)이 각기 다름

### BP-04: 밀약의 그림자 (숨겨진 트랙, SQ-04 연계)
- **상황**: 고구려가 신라에 밀사를 보내 암묵적 불간섭을 제안 — 발견 및 수락 여부가 숨겨진 분기
- **선택지**:
  - 🅰️ 밀약 수락: 장기 결과 — 고구려 압박 완화, 그러나 발각 시 백제·가야 양쪽의 신뢰 추가 손실 / 플래그: `GOGURYEO_pact = TRUE`
  - 🅱️ 거부: 플래그: `GOGURYEO_pact = FALSE`(기본값)
- **발견 조건**: SQ-04 완료 + `TREATY_clarity = LOW` 또는 `NONE`(모호한 상황일수록 밀약이 성사되기 쉬움)
- **합류 지점**: 히든 엔딩(아래) 조건에 사용

### BP-05: 양다리의 발각 (SQ-03 연계)
- **상황**: 가야의 이중 외교가 발각될 위기
- **선택지**: 숨김 성공 / 발각 — 결과는 `GAYA_favor_baekje`, `GAYA_favor_silla` 두 누적 수치에 반영
- **합류 지점**: 엔딩 에필로그의 "가야의 운명" 서술에 반영(흡수 여부)

## 엔딩 구조

### 엔딩 A: 중흥의 대가 (백제 중심, 비극적 정석)
- **조건**: `GWANSAN_outcome = KING_DIES`
- **에필로그 요약**: 성왕은 죽었으나 그 죽음이 백제를 한동안 결집시킨다. 여창이 복수심을 안고 즉위한다.
- **감정 톤**: 비극적, 그러나 완결감 있는 "역사 그대로의" 엔딩

### 엔딩 B: 삼한의 설계자 (신라 중심, 실용주의 승리)
- **조건**: `SILLA_raid_scope = FULL` AND `GWANSAN_outcome != KING_SPARED`
- **에필로그 요약**: 신라가 한강을 완전히 장악하고, 진흥왕은 삼한 통합의 발판을 마련한 왕으로 역사에 남는다. 다만 "신의 없는 왕"이라는 평가도 함께 남는다.
- **감정 톤**: 아이러니한 승리 — 이겼지만 깨끗하지 않다

### 엔딩 C: 끊어진 저울 (양국 공멸형)
- **조건**: `TREATY_clarity = NONE` AND `SILLA_raid_scope = FULL` AND `GWANSAN_outcome = KING_DIES`
- **에필로그 요약**: 신뢰의 완전한 붕괴로 양국 모두 수십 년간 소모적 전쟁에 묶인다. 가야는 이 틈에 흡수되거나 완전히 고립된다.
- **감정 톤**: 가장 어두운 엔딩, 그러나 "정치적 현실"에 대한 냉철한 성찰로 완결감 부여

### 엔딩 D: 유예된 전쟁 (신중한 관리형)
- **조건**: `TREATY_clarity = HIGH` AND `SILLA_raid_scope = PARTIAL` AND `GWANSAN_outcome = KING_CAPTURED` OR `KING_SPARED`
- **에필로그 요약**: 전면전을 피하고 외교로 수습한다. 양국 모두 상처는 입었으나 완전한 파국은 피한다. 다음 세대의 숙제로 남는다.
- **감정 톤**: 열린 결말 — 희망과 불안이 공존

### 히든 엔딩: 북방의 그림자 (고구려 밀약 루트)
- **조건**: `GOGURYEO_pact = TRUE` AND `GWANSAN_outcome != KING_DIES`
- **에필로그 요약**: 신라가 고구려와의 암묵적 밀약으로 전력을 아껴 백제와의 결전에서 전례 없는 우위를 가져간다. 그러나 이 사실이 역사에 기록되지 않은 채 묻힌다 — 플레이어만이 아는 진실
- **감정 톤**: 음모론적 반전, 발견의 재미
- **힌트**: SQ-04에서 고구려 내부 문서를 조사하면 암시가 제공됨

### 히든 엔딩: 쇠의 나라 (가야 생존 루트)
- **조건**: `GAYA_favor_baekje`와 `GAYA_favor_silla`가 둘 다 임계값(각 40) 이상 — 즉 양쪽 모두에게 신뢰를 유지한 경우
- **에필로그 요약**: 대가야가 양쪽 어디에도 완전히 먹히지 않고 교역 거점으로서 독자적 지위를 더 오래 유지한다
- **감정 톤**: 작은 승리의 카타르시스 — 거대사의 틈새에서 지켜낸 생존
- **힌트**: SQ-03을 양쪽 모두와 우호적으로 종료하면 암시

## 플래그 시스템

### 이진/열거형 플래그
| 플래그명 | 설정 시점 | 영향 | 관련 퀘스트 |
|---------|---------|------|-----------|
| `TREATY_clarity` (HIGH/LOW/NONE) | MQ-01 | 신뢰 변동폭, 명분 배분 | MQ-01~04 전체 |
| `SILLA_raid_scope` (PARTIAL/FULL) | MQ-02 | 영토·신뢰 트레이드오프 | MQ-02~04 |
| `BAEKJE_response` (PREEMPT/IGNORE) | MQ-02 | 전쟁 준비도 | MQ-03~04 |
| `GWANSAN_outcome` (KING_DIES/CAPTURED/ABSENT/SPARED) | MQ-04 | 엔딩 분기 핵심 | MQ-04, 엔딩 |
| `GOGURYEO_pact` (TRUE/FALSE) | SQ-04 연계 | 히든엔딩 조건 | SQ-04 |

### 수치 플래그 (누적)
| 플래그명 | 범위 | 증감 조건 | 임계값별 결과 |

| `TRUST_baekje_silla` | 0~100 | BP-01·BP-02 선택에 따라 가감 | 20 이하: 엔딩 C 유도 / 60 이상: 엔딩 D 유도 |
| `REL_isabu` | 0~100 | BP-02에서 위임 선택, SQ-05 결과 | 70 이상: 신라 루트 조력자 강화 이벤트 |
| `REL_seongwang_yeochang` | -50~50 | MQ-02, MQ-03 선택 | -20 이하: 여창의 독단 리스크 상승 |
| `GAYA_favor_baekje` / `GAYA_favor_silla` | 0~100 각각 | SQ-03 선택 | 둘 다 40+: 히든엔딩(쇠의 나라) |

## 분기 흐름 다이어그램
```
BP-01(협정)
   │
BP-02(기습/대응) ──┬── (위임) → REL_isabu↑
   │                │
   ├── SQ-03(가야) ──→ BP-05(양다리 발각) → GAYA_favor
   ├── SQ-04(고구려) ─→ BP-04(밀약) → GOGURYEO_pact
   │
BP-03(관산성) ── KING_DIES ────→ 엔딩 A / (조건 겹침) 엔딩 C
             ── KING_CAPTURED ─→ 엔딩 D
             ── KING_ABSENT ───→ 엔딩 D(변형)
             ── KING_SPARED ───→ 엔딩 D / 히든(북방의 그림자) 조건 보조
```
