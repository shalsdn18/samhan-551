# 입력 정리

## 장르 / 배경
- 역사 전략 게임 — 한국 삼국시대(백제, 고구려, 신라, +가야)
- 레퍼런스: 삼국지토탈워, 크루세이더킹즈(CK), 하츠오브아이언4(HOI4), 림월드, 워해머토탈워, 문명6, 삼국지14, 토탈워 시리즈 전반, 마운틴앤블레이드/배너로드, 유로파(EU), 빅토리아, 스텔라리스

## 핵심 방향
- **대전략(지도/외교/경제) + 인물 드라마(가문·특성·관계) 중심**
- 전투는 보조 시스템 (자동 계산 또는 경량 전술)

## 비대칭 세력 설계 아이디어 (사용자 제시)
- **신라**: 골품제 — 성골/진골/6두품 관직 상한, 신분 불만이 반란·망명으로 이어짐
- **고구려**: 5부 연합, 왕권-귀족 긴장, 산성 방어망, 청야전술
- **백제**: 해상 교역, 22담로 왕족 파견
- **가야**: 철 생산 연맹, 약소국 하드모드 진영

## 주요 역사 이벤트 후보
- 수·당 침공 (살수대첩, 안시성)
- 나당동맹 외교 딜레마
- 불교 전래

## 인물 시스템
- 화랑도 / 태학·경당 — 인재 육성
- 특성과 관계 기반 드라마 (림월드식)

## 플레이 폼 (미확정, 톤 결정에 영향)
1. CK·삼국지14식 — 대전략+인물 중심, 전투 자동계산
2. 마운트앤블레이드식 — 1인 장수 샌드박스
3. 턴제 지도 + 경량 전술전투 (토탈워 라이트)

→ 오케스트레이터 판단: 사용자가 가장 많이 언급·강조한 "대전략+인물 드라마, 전투는 보조"에 맞춰 **①번(CK·삼국지14 계열)을 기본 전제**로 세계관을 설계한다. (사용자가 원하면 ②③로 재조정 가능)

## 범위
- 풀 파이프라인 (세계관 → 퀘스트 → 대사 → 분기 → 검증)
- 시대 범위: 4세기 근초고왕 전후 ~ 7세기 삼국통일 전야 중 한 구간을 특정해 설계 (아래 세계관 문서에서 확정)
